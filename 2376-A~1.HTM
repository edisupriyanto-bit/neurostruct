3. Methodology

# 3.1 Design Assumptions

Typical Bali villa beam: 200×400 mm to 300×600 mm, span 4–6 m, f’c = 25 MPa, fy = 400 MPa. Concrete volume includes 5% wastage; formwork uses plywood with 3-time reuse factor. Seismic detailing per SNI 1726: stirrup spacing ≤ d/4.

# 3.2 Analytical Equations (Copy-Paste Ready for Word)

Concrete volume per beam (including stirrup embedment allowance):

\[ V_c = L \times b \times h + n_s \times V_{stirrup} \]

where \( L \) = length (m), \( b \) = width (m), \( h \) = depth (m), \( n_s \) = number of stirrup sets, \( V_{stirrup} \) = stirrup volume per set.

Rebar quantity (longitudinal + stirrups):

\[ W_r = \rho \times (A_s L + n_{st} \times L_{st} \times \pi d_{st}^2 / 4) \]

where \( \rho \) = steel density (7850 kg/m³), \( A_s \) = main bar area, \( n_{st} \) = stirrup legs.

Formwork area (sides + soffit):

\[ A_f = 2 \times (L \times h) + (L \times b) \]

adjusted by reuse factor \( R = 3 \) (cost per m² = unit price / R).

Seismic cost multiplier for detailing:

\[ C_{seismic} = 1 + 0.15 \times (S_d / S_{base}) \]

where \( S_d \) = design stirrup spacing, \( S_{base} \) = non-seismic spacing.

Total RAB for beam work:

\[ RAB = (V_c \times C_{conc}) + (W_r \times C_{rebar}) + (A_f / R \times C_{form}) + C_{labor} + C_{seismic} \]

All equations use standard LaTeX/KaTeX formatting for direct import into Microsoft Word without distortion.

# 3.3 Step-by-Step Contractor Protocol (Lesser-Known Tips)

1. Extract exact beam dimensions from structural drawings.

2. Apply seismic stirrup multiplier before volume calculation.

3. Deduct lap-length overlaps only once per bar run.

4. Include 8–12% humidity/wastage factor for tropical formwork.

5. Use BIM or spreadsheet auto-calculation for instant sensitivity analysis.
